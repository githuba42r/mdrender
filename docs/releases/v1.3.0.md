# MDRender 1.3.0

Released 2026-11-06.

## Downloads

* **Android**: `mdrender-1.3.0-release-unsigned.apk` (sideload; not Play-signed)
* **Linux**: `.deb` / `.rpm` / Alpine `.apk` / Arch `.pkg.tar.zst`
* **CLI**: `mdrender-send` standalone binary (Linux, Windows, macOS) and installers
* **Server**: `docker pull ghcr.io/githuba42r/mdrender-server:1.3.0`

All assets: https://github.com/githuba42r/mdrender/releases/tag/v1.3.0

### Features

* feat(browser): Download item in the file long-press menu
* feat(viewer): HTML rendering and local video playback
* feat(push-history): expire history after 7 days on device and server
* feat(cloudpush): silent downloads — remove all cloud push notifications
* feat(viewer): delete/move context menu in the image viewer

# MDRender 1.2.0

## Downloads

* **Android**: `mdrender-1.2.0-release-unsigned.apk` (sideload; not Play-signed)
* **Linux**: `.deb` / `.rpm` / Alpine `.apk` / Arch `.pkg.tar.zst`

Register a new client

  1. On the machine that will push, run: 
    tools/localsend-send/localsend-send.py --enrol --server {{ server_url }}
  2. It prints a verification URL. Open it in this signed-in browser and either click Complete registration, or read the short one-time code off the page and type it into the waiting terminal. Either way the tool writes ~/.config/mdrender/push-credentials.json.
  3. Push files to a paired device by name: 
    tools/localsend-send/localsend-send.py --name "<device-name>" file.pdf
    The curl wrapper works the same way: 
    tools/push-to-phone.sh --target "<device-name>" file.pdf

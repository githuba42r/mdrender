{# How to install and enrol a CLI client. Expects `server_url` and `release`. #} {% set assets = release.assets if release else [] %}

Register a new client

  1. Install mdrender-send on the machine that will push. {% if assets %}
    {% for a in assets %} {% endfor %}
    PlatformDownload
    {{ a.platform }} {{ a.name }}
    {% else %}

    Download the package for your OS from the releases page: {{ release.page }}.

    {% endif %}

    Linux packages install the mdrender-send command (run mdrender-send --version to check).

  2. On that machine, run: 
    mdrender-send --enrol --server {{ server_url }}
  3. It prints a verification URL. Open it in this signed-in browser and complete the registration. Credentials are written to ~/.config/mdrender/push-credentials.json.
  4. List the devices you can send to — paired phones and LAN receivers: 
    mdrender-send --list --names
  5. Push files to one of those devices by name: 
    mdrender-send --name "<device-name>" file.pdf
